# ELIXR

ELIXR for Android TV and Google TV.

**Download:** [ELIXR.apk](https://github.com/Letdown27/elixr/releases/latest/download/ELIXR.apk) (always the newest version)

## Installing on a TV

1. On the TV, install **Downloader** (by AFTVnews) from the Play Store.
2. Open Downloader, type **tinyurl.com/elixrtv** and choose **Install**.
3. If the TV asks, allow Downloader to install apps, then choose **Install** again.

After that, ELIXR updates itself: Settings › About › Check for updates.
