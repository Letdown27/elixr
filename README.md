# ELIXR

ELIXR for Android TV, Google TV and Fire TV.

**Download:** [ELIXR.apk](https://github.com/Letdown27/elixr/releases/latest/download/ELIXR.apk) (always the newest version)

## Installing on a TV

1. On the TV, install **Downloader** (by AFTVnews) from the Play Store.
2. Open Downloader, type **tinyurl.com/elixrtv** and choose **Install**.
3. If the TV asks, allow Downloader to install apps, then choose **Install** again.

### On a Fire TV

1. Install **Downloader** (by AFTVnews) from the Amazon Appstore.
2. Go to Settings › My Fire TV › About and select the device name 7 times, until it says you're a developer.
3. Go to Settings › My Fire TV › Developer options › Install unknown apps (older Fire TVs: Apps from Unknown Sources) and turn on **Downloader**.
4. Open Downloader, type **tinyurl.com/elixrtv**, choose **Go**, then **Install**.

The Fire TV Stick 4K Select (2025) can't install apps from outside Amazon's store, so ELIXR can't run on it.

After that, ELIXR updates itself: Settings › About › Check for updates.
